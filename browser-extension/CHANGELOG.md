# 0.1.1 · 2026-10-19

- 接入视频分析明细统计：标题、BV/AV/CID、分 P、总结详细程度、时间与结果；后台按视频汇总或逐次任务查看，可按日期、安装编号和客户端筛选。
- 每次任务以随机编号去重；离线保存并重试；统计网络独立于总结。仅记录新版主动总结的已核验视频，不上传字幕、笔记正文或凭据。
- 保留原用户、功能次数、权限和本地设置。视频明细保留最近 90 天。

# 0.1.0 · 2026-10-15

- Chrome / Edge Manifest V3 扩展，网页浮窗和原生侧栏。
- 自动识别当前视频 / 分 P；切换视频停止旧任务并清除旧结果，支持手动粘贴链接。
- 完整字幕提取、收起与内部滚动、复制、TXT / SRT 导出、TXT / SRT / VTT 导入。
- 简洁、标准、详细三个整段总结档位，Chat / Responses 兼容接口，流式状态、一次整段重试、截断和格式错误拒绝保存。
- 本地历史笔记、Markdown 导出、字幕引用及原视频时间点跳转。
- 标题括号、视频编号、CID、分 P 和字幕来源校验。默认会话密钥，接口按域名授权。
