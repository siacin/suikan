# 隐私与权限

随看浏览器版 0.1.1，作者 Cin。

- 仅在用户操作时读取指定 B 站视频的公开元信息及可访问字幕；请求 B 站时通过浏览器携带对应站点登录会话。扩展不读取 Cookie API、不导出 Cookie、不保存账号密码。Cookie 限制可能影响可下载的字幕。
- 点击总结时，将视频标题和完整字幕发给用户配置的模型接口。仅提取字幕时不调用模型。模型请求不携带 B 站 Cookie；接口地址或密钥不会发送给 B 站。
- 默认密钥仅保存在 `chrome.storage.session`。用户勾选记住密钥后，存于扩展本地存储，不同步云端。扩展存储限制为可信扩展上下文，内容脚本不读取配置或密钥；网站无法访问跨域扩展 iframe 的内容。持有本机浏览器配置或开发者工具访问权限的人仍可能读取本地密钥。
- 本地 IndexedDB 保存最近 30 篇完整笔记及其引用字幕，导出内容不包含密钥。卸载扩展会清除本地数据，请按需备份。
- 本版默认接入作者的腾讯 CloudBase 使用统计后台。打开面板上报随机安装 UUID、版本和北京时间日期；主动总结已核验 B 站视频时，上报任务随机编号、标题（最多 256 字符）、BV/AV/CID/分 P、开始结束时间、详细程度和成功/失败/取消结果。服务端仅存安装编号的 SHA-256，不使用 B 站账号 ID、广告 ID 或设备硬件标识。不会遍历或收集浏览历史。
- 不上报字幕、提示词、总结正文、模型地址、API Key、Cookie。仅提取字幕、查看历史、模型连接测试和导入文稿不产生视频统计。页面导航或用户取消时尽力记录取消；关闭浏览器等情况可能只留下“未完成”。
- 统计服务：https://suikan-d9gi643yk8b95195e.service.tcloudbase.com/ 。管理员使用独立口令查询视频汇总及随机安装编号关联的任务。视频明细保留最近 90 天；原安装/日活统计按服务端既有策略保留。应用无第三方广告跟踪 SDK。
- 本机统计队列离线最多保存 1000 个待报任务、最近 31 天。网络失败约 15 分钟后重试，不影响字幕和模型任务；重试通过事件编号去重。卸载/清除扩展数据会清空本机队列并产生新安装编号。无法补采旧版笔记。

## 权限用途

| 权限 | 用途 |
|---|---|
| storage | 保存设置和会话内密钥 |
| alarms | 后台每约 15 分钟尝试重发失败统计，不执行视频分析 |
| 腾讯云统计域名访问 | 发送本文列明的安装及视频任务元信息，不发送字幕或凭据 |
| sidePanel | 在 Chrome / Edge 侧栏显示界面 |
| activeTab | 识别用户当前视频标签页 |
| clipboardWrite | 用户点击时复制字幕和笔记 |
| B 站及字幕 CDN 站点访问 | 读取当前视频、官方元信息和字幕 |
| declarativeNetRequestWithHostAccess | 仅为本扩展发往 B 站 API / 字幕 CDN 的请求设置 B 站 Referer；不改变普通网页请求 |
| 用户选择的模型域名（可选） | 用户保存设置时按域名申请，访问该模型 API |

代码不加载远程可执行脚本，不使用 eval；模型内容和字幕以纯文字展示，不作为 HTML 执行。
